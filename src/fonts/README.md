# Fonts

The site uses three self-hosted typefaces, loaded in `index.ts` with `next/font/local`:

- **Instrument Serif** (SIL Open Font License) is included here.
- **Clash Display** and **Satoshi** (Indian Type Foundry, via Fontshare) are free to use but their licence does not allow redistributing the font files, so they are not in this repository.

To build the project, download both families from [fontshare.com](https://www.fontshare.com/) and place the `.woff2` files in this folder with these names:

```
ClashDisplay-400.woff2  ClashDisplay-500.woff2  ClashDisplay-600.woff2  ClashDisplay-700.woff2
Satoshi-400.woff2       Satoshi-500.woff2       Satoshi-700.woff2       Satoshi-900.woff2
```
